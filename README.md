# Python Function Mastery

A hands-on project for learning Python functions through examples, exercises, and interview practice. The examples use Python automation-testing scenarios where practical.

## Lessons

The root folder contains 19 lesson files:

1. Function basics
2. Parameters and arguments
3. Positional and keyword arguments
4. Default arguments
5. Return vs print
6. Multiple return values
7. `*args` and `**kwargs`
8. Variable scope
9. Mutable vs immutable arguments
10. Functions calling functions
11. Lambda functions
12. First-class functions
13. Closures
14. Decorators
15. `functools.wraps`
16. Generators and `yield`
17. Generator expressions
18. Positional-only and keyword-only parameters
19. Docstrings and type hints

## Exercises

The `exercises/` folder contains practice examples for each lesson and `mock_interview.py` for interview review. The files use descriptive names, such as `function_basics.py` and `decorators.py`.

## Running a file

Run a lesson or exercise from the repository root with Python 3:

```bash
python 01_function_basics.py
python exercises/function_basics.py
